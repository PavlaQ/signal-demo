Demo Web SDK v16 — zapis uzytkownika pod wlasnym ID, tagi i zdarzenia na zywo.

1 Zapis uzytkownika

Podaj ID uzytkownika z Twojego systemu. Trafi do OneSignala jako External ID i to po nim bedziesz pozniej wysylac powiadomienia pojedynczo.

Wpisz ID, zeby odblokowac zapis.

Zapis zaklada tez segment o nazwie rownej Twojemu ID, zebys mogl wybrac te osobe w kompozytorze w panelu. Wymaga to zmiennych ONESIGNAL_REST_API_KEY i ONESIGNAL_APP_ID na Vercelu — bez nich reszta demo dziala normalnie, a log powie, czego brakuje.

Zgoda jest zablokowana na poziomie przegladarki. Odblokuj ja w ustawieniach strony (ikona klodki w pasku adresu) i odswiez — inaczej prompt sie nie pokaze.

3 Wyslij do tego uzytkownika

Gotowe polecenie celujace w Twoje External ID. Podmien TWOJ_REST_API_KEY i wklej do terminala. 

—

Klucz znajdziesz w OneSignal → Settings → Keys & IDs → REST API Key. Nie wklejaj go do kodu strony — z przegladarki kazdy moglby go odczytac.
